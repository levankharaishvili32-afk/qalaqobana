# ქალაქობანა ონლაინ 🏙️

მეგობრების ჯგუფისთვის (4–10 მოთამაშე) განკუთვნილი ქალაქობანა: ყველა ერთდროულად თამაშობს ბრაუზერიდან, რეგისტრაციის გარეშე.

---

## 1. როგორ გავუშვა ჩემს კომპიუტერზე

### ერთჯერადი მომზადება

1. დააყენეთ **Node.js** (LTS ვერსია) საიტიდან <https://nodejs.org>. ინსტალაციისას ყველგან დააჭირეთ „Next".
2. პროექტის საქაღალდე მოათავსეთ **მოკლე მისამართზე**, მაგალითად `C:\qalaqobana` ან სამუშაო მაგიდაზე.
   Windows-ზე ძალიან გრძელი მისამართის შემთხვევაში (260 სიმბოლოზე მეტი) ინსტალაცია შეცდომით მთავრდება.

### გაშვება — მარტივი გზა (Windows)

ორჯერ დააწკაპუნეთ ფაილზე **`start-game.bat`**. პირველ გაშვებაზე ის თავად ჩამოტვირთავს საჭირო ბიბლიოთეკებს (1–2 წუთი), ააწყობს საიტს და გაუშვებს სერვერს. შემდეგ ბრაუზერში გახსენით <http://localhost:3000>.

გასათიშად დახურეთ შავი ფანჯარა.

### გაშვება — ხელით (ნებისმიერი სისტემა)

გახსენით ტერმინალი პროექტის საქაღალდეში (Windows-ზე: საქაღალდეში მისამართის ველში ჩაწერეთ `cmd` და დააჭირეთ Enter) და გაუშვით რიგრიგობით:

```bash
npm install
```

```bash
npm run play
```

როცა გამოჩნდება `ქალაქობანა გაშვებულია: http://localhost:3000`, გახსენით ეს მისამართი ბრაუზერში.

### როგორ გავტესტო მარტომ

თამაშს მინიმუმ 4 მოთამაშე სჭირდება. მარტო გასატესტად ორი გზაა:

- **ბოტები თქვენს ოთახში.** შექმენით ოთახი ბრაუზერში, შემდეგ მეორე ტერმინალში გაუშვით (კოდის ნაცვლად ჩაწერეთ თქვენი ოთახის კოდი):

  ```bash
  npm run friends -- ABC123 5
  ```

  5 ბოტი შემოვა, თავად შეავსებს ველებს, მისცემს ხმას და დააჭერს „მზად ვარ"-ს.

- **რამდენიმე ჩანართი.** ერთ ბრაუზერში ყველა ჩანართი ერთი და იგივე მოთამაშეა. სხვადასხვა მოთამაშისთვის მისამართს ბოლოში მიუწერეთ `?p=1`, `?p=2` და ა.შ., მაგალითად `http://localhost:3000/r/ABC123?p=2`.

იმავე Wi-Fi-ზე მყოფ ტელეფონებს შეუძლიათ შემოვიდნენ მისამართით `http://თქვენი-კომპიუტერის-IP:3000`. ინტერნეტით სათამაშოდ საჭიროა deploy (იხ. ნაწილი 5).

### ტესტები

| ბრძანება | რას აკეთებს |
|---|---|
| `npm test` | unit ტესტები: ქულების წესი, ნორმალიზაცია, ასოს არჩევა |
| `npm run bots` | 10 ბოტი ატარებს სრულ თამაშს დაჩქარებული დროით და ამოწმებს წესებს (დაახლოებით 15 წამი) |

## 2. როგორ დავამატო კატეგორია

გახსენით ფაილი [`shared/config/categories.ts`](shared/config/categories.ts) და სიაში ჩაამატეთ ერთი ხაზი:

```ts
export const CATEGORIES: Category[] = [
  { id: 'country', name: 'ქვეყანა', icon: '🌍' },
  // ...
  { id: 'river', name: 'მდინარე', icon: '🏞️' },   // ← ახალი კატეგორია
];
```

- `id` — უნიკალური ლათინური სახელი, ჰარების გარეშე
- `name` — რასაც მოთამაშეები ხედავენ
- `icon` — ემოჯი
- `allowLatin: true` — დაამატეთ, თუ ამ კატეგორიაში ლათინური პასუხიც მისაღებია (როგორც „ბრენდში")

შეინახეთ ფაილი და თავიდან გაუშვით `npm run play`. სხვა ფაილის შეცვლა საჭირო არ არის.

მხოლოდ ერთი თამაშისთვის კატეგორიის დამატება ჰოსტს ლობიდანაც შეუძლია, კოდის გარეშე.

**ტრანსლიტერაციის ცხრილი** (რომელი ლათინური ასო შეესაბამება ქართულს ბრენდებში) არის ფაილში [`shared/config/alphabet.ts`](shared/config/alphabet.ts), `LATIN_PREFIXES`. იქვეა რთული ასოების სია (`HARD_LETTERS`).

## 3. როგორ შევცვალო ქულების წესი

ქულების მთელი ლოგიკა ერთ ფაილშია: [`shared/scoring.ts`](shared/scoring.ts).

**ქულების ოდენობის შეცვლა** — შეცვალეთ რიცხვები ფაილის დასაწყისში:

```ts
export const POINTS = {
  only: 20,    // მიღებული პასუხი მხოლოდ ერთ მოთამაშეს აქვს
  unique: 10,  // უნიკალური პასუხი
  shared: 5,   // იგივე პასუხი სხვასაც აქვს
  none: 0,     // ცარიელი, არასწორი ასო ან უარყოფილი
};
```

**თვით წესის შეცვლა** (მაგ. როდის ითვლება პასუხი უარყოფილად) — იმავე ფაილში:

- `isRejectedByVotes` — რამდენი ხმაა საჭირო უარყოფისთვის (ახლა: ნახევარზე მეტი)
- `scoreRound` — როგორ ნაწილდება ქულები
- `findWinners` — ვინ არის გამარჯვებული (ფრის შემთხვევაში გამარჯვება იყოფა)

პასუხების შედარების წესი (რა ითვლება „ერთნაირად") არის ფაილში [`shared/normalize.ts`](shared/normalize.ts). შედარებისას ჰარები, დეფისები და პუნქტუაცია არ ითვლება, ამიტომ „ნიუ-იორკი", „ნიუ იორკი" და „ნიუიორკი" ერთნაირია.

ცვლილების შემდეგ გაუშვით `npm test`. თუ რიცხვები შეცვალეთ, ზოგი ტესტი ჩავარდება — ეს ნორმალურია, ტესტებში მოსალოდნელი ქულებიც შესაცვლელია ([`tests/scoring.test.ts`](tests/scoring.test.ts)).

დროები (ათვლა, „სტოპ!"-ის 10 წამი, შემოწმების 90 წამი) და ლიმიტები (მოთამაშეები, რაუნდები) არის ფაილში [`shared/config/gameDefaults.ts`](shared/config/gameDefaults.ts).

## 4. თამაშის წესები მოკლედ

- ყოველ რაუნდში სერვერი ირჩევს შემთხვევით ასოს (ერთ თამაშში ასო არ მეორდება).
- ყველა წერს სიტყვებს ამ ასოზე. ვინც ყველა ველს შეავსებს, შეუძლია დააჭიროს „სტოპ!"-ს — დანარჩენებს 10 წამი რჩებათ.
- შემოწმებისას ყველა ხედავს ყველა პასუხს. სხვის პასუხზე დაჭერით მას არასწორად ნიშნავთ; თუ ონლაინ მოთამაშეების (ავტორის გარდა) ნახევარზე მეტმა მონიშნა, პასუხი უარყოფილია.
- ჰოსტს შეუძლია ნებისმიერი პასუხის იძულებით მიღება/უარყოფა და ორი პასუხის „ერთნაირად" გაერთიანება.
- ქულები: **20** — მხოლოდ თქვენ გაქვთ მიღებული პასუხი, **10** — უნიკალური, **5** — სხვასაც იგივე აქვს, **0** — ცარიელი, არასწორი ასო ან უარყოფილი.
- გვერდის განახლების ან ინტერნეტის გაწყვეტის შემდეგ მოთამაშე იმავე ადგილზე ბრუნდება, იმავე ქულებით.
- შუა თამაშში შემოსული მოთამაშე 0 ქულით იწყებს და შემდეგი რაუნდიდან ერთვება.
- თუ ჰოსტი გავიდა ან 60 წამზე მეტხანს გაითიშა, ჰოსტობა გადადის ყველაზე დიდხანს მყოფ მოთამაშეზე.
- თუ 4-ზე ნაკლები მოთამაშე დარჩა, რაუნდი სრულდება და ჰოსტი წყვეტს, გაგრძელდეს თუ არა.

## 5. ინტერნეტში გამოქვეყნება (deploy)

საიტი ერთი Node სერვერია, რომელიც frontend-საც ემსახურება, ამიტომ ნებისმიერი ჰოსტინგი გამოდგება, რომელიც Node.js-ს და WebSocket-ს უჭერს მხარს. პარამეტრები ყველგან ერთნაირია:

- **Build command:** `npm install && npm run build`
- **Start command:** `npm start`
- პორტს სერვერი თავად იღებს `PORT` ცვლადიდან.

ფასები იცვლება — ანგარიშის შექმნამდე გადაამოწმეთ ოფიციალურ გვერდზე.

### ვარიანტი A — Render (უფასოდ დასაწყებად)

- **ფასი:** უფასო გეგმა — $0. სერვერი 15 წუთის უმოქმედობის შემდეგ „იძინებს" და პირველი შესვლისას დაახლოებით 1 წუთში იღვიძებს. მუდმივად ჩართული სერვერი (Starter) — დაახლოებით $7 თვეში.
- **ნაბიჯები (მარტივი გზა — Blueprint):** რეპოზიტორიის ძირში არის ფაილი `render.yaml`, რომელშიც ყველა პარამეტრი უკვე წერია.
  1. ატვირთეთ პროექტი GitHub-ზე (საჭიროა GitHub-ის ანგარიში).
  2. <https://render.com> → **Sign in with GitHub**.
  3. **New → Blueprint** → აირჩიეთ რეპოზიტორია `qalaqobana` → **Apply**.
  4. რამდენიმე წუთში მიიღებთ მისამართს სახით `https://qalaqobana-xxxx.onrender.com`.
- **ნაბიჯები (ხელით):** **New → Web Service** → აირჩიეთ რეპოზიტორია და შეავსეთ:
  - **Root Directory:** `qalaqobana` (პროექტი რეპოზიტორიაში ქვესაქაღალდეშია)
  - **Build Command:** `npm install && npm run build`
  - **Start Command:** `npm start`
  - **Instance Type:** `Free`

### ვარიანტი B — Railway (იაფი, არ იძინებს)

- **ფასი:** Hobby გეგმა — $5 თვეში (მოიცავს $5-ის მოხმარებას, რაც ამ ზომის თამაშს ჩვეულებრივ ჰყოფნის). ახალ ანგარიშს აქვს ერთჯერადი საცდელი კრედიტი.
- **ნაბიჯები:**
  1. ატვირთეთ პროექტი GitHub-ზე.
  2. <https://railway.com> → ანგარიშის შექმნა → **New Project → Deploy from GitHub repo**.
  3. Settings-ში ჩაწერეთ Build და Start ბრძანებები, შემდეგ **Networking → Generate Domain**.

### რა უნდა იცოდეთ

- ოთახები სერვერის მეხსიერებაში ინახება. სერვერის გადატვირთვისას (ან Render-ის უფასო გეგმაზე „დაძინებისას") მიმდინარე თამაშები იკარგება.
- ცარიელი ოთახი 30 წუთის შემდეგ ავტომატურად იშლება.

## 6. პროექტის სტრუქტურა

```
shared/            საერთო ლოგიკა (სერვერიც და საიტიც იყენებს)
  config/          კატეგორიები, ანბანი, ლიმიტები და დროები
  scoring.ts       ქულების წესი
  normalize.ts     პასუხების ნორმალიზაცია და ასოს შემოწმება
  keyboard.ts      QWERTY → ქართული
server/            სერვერი: ოთახები, ასოს არჩევა, ფაზები, ტაიმერები
client/            საიტი (React + Tailwind)
tests/             unit ტესტები
scripts/bots.ts    10 ბოტის ავტომატური შემოწმება
scripts/friends.ts ბოტები თქვენს ოთახში ხელით ტესტირებისთვის
```

სერვერი ავტორიტეტულია: ასო, ტაიმერები, ხმები და ქულები მხოლოდ სერვერზე ითვლება. ასო ირჩევა `crypto.randomInt`-ით და მოთამაშეებს მხოლოდ „ტრიალის" დასრულებისას ეგზავნება; წერის დროს სხვისი პასუხები ბრაუზერში საერთოდ არ მოდის.
